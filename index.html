日本語 / Japanese

概要

このパッチは、Steam版で制限されている成人向け表現を有効化するための 「18+ エクストラパッチ（ErisPatch）」です。 Steam版ゲーム本体とは別の、外部配布コンテンツになります。

導入方法

このパッチは ErisPatch フォルダをゲームの .exe と同じ場所に置くだけで適用されます。

  1. 上部リンクから eris_patch.zip をダウンロードする。
  2. ZIP を解凍する。
  3. 中にある ErisPatch フォルダをコピーする。
  4. ゲーム本体のフォルダに、以下のように配置する： 
    Eris_in_the_Abyss
├ Eris_in_the_Abyss.exe
└ ErisPatch    ← このフォルダを配置
  5. ゲームを起動し、18+ コンテンツが有効になっていることを確認する。

トラブルシューティング

■ パッチが反映されない場合

  • ErisPatch フォルダが .exe と同じ場所にあるか確認する。
  • フォルダ名を変更していないか確認する（ErisPatch のままにする）。
  • ゲームを一度終了し、再起動する。

■ ウイルス警告について

自作ゲームでは、セキュリティソフトが誤検知する場合があります。必要に応じて除外設定をご検討ください。

  • ゲームをアップデートした場合、パッチを再配置する必要がある場合があります。

English

Overview

This patch, called "ErisPatch", restores restricted 18+ content that is removed in the Steam version. It is distributed externally and is not part of the official Steam build.

Installation

This patch works by placing the ErisPatch folder next to the game’s .exe file.

  1. Download eris_patch.zip from the link above.
  2. Unzip the downloaded ZIP file.
  3. Copy the ErisPatch folder.
  4. Place it in the same directory as the game’s executable, for example: 
    Eris_in_the_Abyss
├ Eris_in_the_Abyss.exe
└ ErisPatch    ← place this folder here
  5. Launch the game and confirm that the 18+ content is active.

Troubleshooting

■ Patch not applied

  • Make sure the ErisPatch folder is in the same directory as the .exe.
  • Do not rename the folder; keep the name as ErisPatch.
  • Close the game completely and restart it.

■ Antivirus warning

False positives may occur with indie / custom game files. If necessary, please add an exception in your antivirus software.

Notes
